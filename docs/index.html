这一类的三条结论

  1. 「Promotion」在俱乐部语境下有两种意思，完全不同。一种是餐饮特价（牛排夜、parmi 夜），一种是博彩抽奖。Broncos 和 Greenbank 的「促销」页面整页都是抽奖，一条菜价都没有；Kedron-Wavell 的「Promotions」页同样如此，餐饮特价另挂在餐厅页上。找吃的别看 Promotions，去看 Specials 或各餐厅页。
  2. 非会员差价非常小，会员费一顿就回本。Easts 明写非会员 +$3；多数俱乐部只印会员价、不印非会员价。会员费本次查到 Broncos $2、Carina $2、Greenbank $5——吃一次牛排夜就赚回来了。
  3. 俱乐部的 Google 分不能和餐厅横向比。4.1–4.3 在餐厅表里是「不及格」，在俱乐部里是正常水平——因为这个分包含了博彩厅、宴会、演出和游乐区。本页把它们单列一节、单列一套闸门，就是为了不让这两组数字混排。

  • Google 众报 Google Maps 的「每人 $X–Y · reported by N people」，用于横向比价，不是账单金额。
  • 评论照片 Rothwell's 与 Longtime Dining 官网菜单链接失效（前者 PDF 实测 404，后者菜单页空白），价格取自 Google 评论里的实体菜单照片——可能是旧版，订位前确认。Rothwell's 牛排区照片对焦不清，未采信具体数字。

已知空白

  • 这份清单不是名录。布里斯班市议会的持牌食品场所登记册有 8,046 条（面向食客 7,020 家），本页收录约 150 家——主闸门「Google ≥4.7 且 ≥200」本来就是极窄的筛子。从那份名录随机抽样还抓出过本页原先漏掉的店（#24 Nekoland、#25 Chocolate Elements），说明全市过闸门的店是几百家量级。完整的普查、抽样与 API 成本推算在 research/brisbane-dining.md。
  • 大众点评、小红书仍然取不到：大众点评跳人机验证（本项目不做验证码），TripAdvisor 对自动访问返回空白页。不过用中文在 Google Maps 搜已经补上了绝大部分缺口——Google 会返回中文分类和这些店的真实分数。
  • 评分用的是镜像值时会滞后：卡在 4.5／4.7 或 200／1,000 边界的店，订位前看一次 Google 实时值（例：Andonis 镜像 4.6、实时已掉到 4.5）。
